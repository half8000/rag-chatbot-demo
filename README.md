# RAG Chatbot Demo

CSVで登録したナレッジを意味の近さで検索し、関連情報を参考に回答を生成するRAG（検索拡張生成）チャットボットです。Next.js、Supabase pgvector、Gemini API、Google OAuthを組み合わせ、質問・回答だけでなく、認証・認可とナレッジ更新も扱います。

> **公開状況：開発中**  
> もともとは社内向けの利用を想定して開発したサービスです。現在、個人のポートフォリオとして外部公開できるよう、架空データと個人環境を使う構成へ再調整しています。このリポジトリには現時点でREADMEのみを掲載しています。ソースコードとデモURLは、公開準備が整い次第追加する予定です。

この公開版に、実在する企業・顧客のデータや社内システムの設定は含めません。

## 解決したい課題

社内の担当者が必要な情報を確認するたびに別部門へ問い合わせると、質問者には回答待ちが生じ、回答側には似た質問への対応が集中します。登録済みナレッジを自然文で検索し、一次回答を得られる仕組みによって、情報を探す負担と反復的な問い合わせを減らすことを目指しています。

## コードに実装している主な機能

- **RAGチャット**：質問と意味が近いナレッジを検索し、Geminiが回答を生成
- **Google OAuth**：許可したドメインのアカウントにログインを限定する構成
- **管理者認可**：管理画面とCSVアップロードAPIの両方で権限を確認
- **CSVナレッジ更新**：新しいデータを全件登録できた場合だけ有効版へ切り替え
- **公開デモモード**：架空データを使い、チャットをログインなしで試せる構成
- **API保護**：入力・リクエストサイズの検証とIP単位の簡易レート制限
- **Cron保護**：ヘルスチェックをBearerトークンで認証
- **非公開Storage**：アップロード元CSVを保存し、最新5件を保持

上記は公開用に準備しているローカルのコードの説明です。現時点で、このリポジトリからコードを取得したり、公開デモへアクセスしたりすることはできません。

## アーキテクチャ

```text
[利用者]
   │ 質問
   ▼
[Next.js / Vercel]
   ├─ 入力検証・利用量制御
   ├─ 質問をベクトル化 ─────────────► [Gemini Embedding API]
   ├─ 類似ナレッジを検索 ───────────► [Supabase / pgvector]
   └─ 質問＋検索結果から回答生成 ───► [Gemini Generate Content API]
   │
   ▼
[回答]

[管理者] ── Google OAuth / 管理者認可
   │ CSVアップロード
   ▼
[全行の埋め込み生成]
   → [新しいデータセットへ登録]
   → [成功時だけ有効版を切替]
   → [元CSVを非公開Storageへ保存]
```

## 設計上のポイント

### 更新途中のデータを利用者へ見せない

CSV更新時には既存データを先に削除せず、新しいデータセットへ全件登録した後、PostgreSQLのトランザクションで有効版を切り替えます。埋め込み生成やDB登録が失敗した場合も、旧データセットを検索対象として維持する設計です。

### 画面とAPIの両方で管理者権限を確認する

管理画面へのアクセスを保護し、CSVアップロードAPIでも管理者権限を再検証します。画面のURLを制限するだけでなく、APIへ直接リクエストされた場合も権限を確認します。

### 秘密情報をブラウザへ渡さない

Supabaseのservice roleキーはサーバー側だけで使用します。データベース側ではRLSを有効にし、検索処理の実行権限も制限します。

### 公開デモの利用量を制御する

チャットAPIには本文・履歴・リクエストサイズの検証とIP単位の簡易レート制限を実装しています。サーバーレス環境ではインメモリ制限だけで全リクエストを一律に制御できないため、本番公開時にはVercel Firewall側の制限も設定する予定です。

### 検索したナレッジを命令として扱わない

検索されたナレッジは回答の参考情報として区切り、ナレッジ内の文章に命令が含まれていても従わないよう生成AIへ指示します。回答APIからは検索結果の生のメタデータをブラウザへ返しません。

## 既知の制約

- 現在の構成は小規模なデモデータを対象としています。3072次元の埋め込みには、現行の実装でベクトルインデックスを使用していません。
- インメモリのレート制限は、複数のサーバーレスインスタンスを横断する厳密な上限にはなりません。
- 生成AIの回答は正確性を保証しません。将来公開するデモも、実際の業務判断には使用できません。
